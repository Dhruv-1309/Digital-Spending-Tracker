HARD RULES FOR THE WHOLE PROJECT:
- Never run `git push`. Never add, change or remove a git remote. Push only if I explicitly type "push".
- Commit locally at the end of each phase and stop.
- Do not modify, move or delete the vanilla app at the repo root. All new code goes in `app/`.
- Do not change Firestore document paths or data shapes.
- Do not change the result of any calculation. Read the original and translate it; do not reinterpret.
- Do not restyle, improve or simplify the UI. Port it exactly.
- Never print, log or commit Firebase config values or secrets.
- Do not add dependencies that are not pre-approved in RULES.md without asking me.
